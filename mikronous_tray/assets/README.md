Assets bundled with the tray app.

- `mikronous*.svg` — original Mikronous icons (cog + circuit), MIT like the rest of the project.
- `fonts/` — Cinzel, Share Tech Mono and Grenze Gotisch, each under the SIL Open Font License 1.1
  (see the `OFL-*.txt` files). Loaded at runtime with QFontDatabase; system fonts are the fallback.
